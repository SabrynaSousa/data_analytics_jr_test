# Desafio - Data Analytics

Este projeto visa resolver um desafio de análise de dados utilizando Python e SQL. O objetivo é carregar dados CSV em um banco de dados SQLite, realizar análises exploratórias e apresentar insights de forma clara.

## Como Rodar o Projeto

1. **Instalar Dependências**:

2. **Carregar Dados no Banco de Dados**:
Execute o script `load_data.py` para carregar os arquivos CSV para o banco de dados SQLite.

3. **Criar Relações entre as Tabelas**:
Execute o script `criar_tabelas.py` para criar a tabela `escolas_alunos` e estabelecer a relação entre escolas e alunos.

4. **Análise Exploratória**:
Execute o script `analise_exploratoria.py` para validar a qualidade dos dados e gerar insights.

5. **Visualização e Storytelling**:
Execute o script `storytelling.py` para visualizar os dados e compartilhar os insights de forma interativa.

## Como Executar o Streamlit

Para rodar o Streamlit, execute o seguinte comando no terminal:
python storytelling.py
Acesse a URL fornecida pelo Streamlit no seu navegador.
